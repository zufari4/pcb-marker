## ✨ Что умеет PCB Marker

- **Открывает Gerber ZIP** — перетащите архив в окно или выберите «Открыть файл» в меню.
- **Показывает обе стороны** — переключайте верхнюю, нижнюю или смотрите их вместе. Масштаб сохраняется.
- **Привязывает рисунок по четырём углам** — учитывает положение и поворот заготовки, сохраняя масштаб 1:1.
- **Помогает проверить маршрут** — визуализация и пробный прогон без касания платы.
- **Рисует дорожки и контактные площадки** — при желании добавляет границы платы.
- **Показывает выполнение** — пройденные участки, положение маркера и процент готовности. Пауза, продолжение и остановка рядом.
- **Даёт настроить движение** — отдельные скорости рисования, переходов, подъёма и опускания Z.
- **Говорит на двух языках** — русский, English или язык системы. Шрифт встроен, интернет для интерфейса не нужен.
- **Экспортирует G-code** и проверяет наличие новых версий по вашему запросу.

## 📥 Установка

### Готовое приложение

[**Скачать последнюю версию →**](https://github.com/zufari4/pcb-marker/releases/latest)

| Файл | Как использовать |
| --- | --- |
| **PCB-Marker-Setup.exe** | Запустите установщик и следуйте подсказкам |
| **PCB-Marker-Windows-x64.zip** | Распакуйте всю папку и откройте `PCB Marker.exe` |

Python и Node.js для готовой Windows-сборки не нужны. ZIP также хранит настройки
в профиле пользователя Windows. Сборки пока без цифровой подписи, поэтому при
первом запуске Windows может показать предупреждение.

### Через npm

Пакет **подготовлен к публикации**, но пока не опубликован в реестре npm.
После публикации установите его командой (нужен Node.js 22.12+):

```sh
npm install -g pcb-marker-desktop
pcb-marker
```

Откроется полноценное приложение с графическим интерфейсом. До публикации
можно установить `.tgz` из [релиза](https://github.com/zufari4/pcb-marker/releases):

```sh
npm install -g ./pcb-marker-desktop-1.0.0.tgz
pcb-marker
```

## 🚀 Первый запуск

1. Закрепите маркер и заготовку. Выполните Home на принтере, убедившись, что маркер и плата не мешают движению.
2. В **Настройках** укажите адрес принтера и данные SSH. Подключитесь, задайте Z касания и отрыв.
3. Откройте Gerber ZIP через первый пункт меню или перетащите файл в окно.
4. В **Привязке по углам** подведите маркер к каждому углу заготовки и считайте координаты.
5. Выберите сторону платы, посмотрите **Визуализацию**, затем выполните **Пробный прогон**.
6. Если всё совпадает, нажмите **Начать рисование**.

При изменении положения платы или маркера привязку нужно выполнить заново.
Сохранённые координаты не заменяют Home после отключения моторов.

## 🖨️ Совместимость

Начальный профиль рассчитан на **Creality K1 SE с Klipper и доступом по SSH**.
Рабочая область: X/Y — 0–220 мм, Z — 0–250 мм. Для других принтеров нужна
проверка совместимости; изменение имени принтера не меняет его профиль.

Поддерживаются верхний и нижний слои меди, контур платы и файлы сверловки
в Gerber ZIP, включая распространённые имена слоёв KiCad и EasyEDA.
Сплошные заливки меди не закрашиваются. Нижняя сторона зеркалится автоматически.

Приложение не выполняет Home автоматически. Если связь пропала, принтер может
продолжить задание — восстановите подключение, чтобы увидеть его состояние.
Процент выполнения является оценкой; завершение подтверждается принтером.
