# Development

Use Node.js 22.12+ and npm on Windows. The desktop app is built with Electron,
React and TypeScript; JSTS and the Gerber parser are bundled at build time.

```sh
npm ci
npm test
npm run build
npm start
npm run test:ui
```

UI checks generate their own sample Gerber and use temporary profiles without
credentials. They must never operate a physical printer. See AGENTS.md for
module boundaries and motion invariants.

## Distribution

```sh
npm run release:win
npm pack
```

`release/latest-build.json` points to the most recent local build directory.
The release command produces an NSIS installer and a runnable ZIP; checksums
are generated by `scripts/release-manifest.mjs`. Builds are currently unsigned.
Only Windows x64 is a supported release target.

Version package.json and package-lock.json together. After validation, push a
matching `vX.Y.Z` tag. GitHub Actions builds both Windows downloads and attaches
them to GitHub Releases. The update button checks the latest stable release;
it never downloads or installs automatically.

## npm

The package name is `pcb-marker-desktop`; the command is `pcb-marker`.
`npm pack` builds and includes the renderer, main process, worker, icons and
licenses. Electron and ssh2 are installed as runtime dependencies. Users do
not need the source or a TypeScript compiler.

To publish after reviewing the archive and signing in to your own npm account:

```sh
npm login
npm publish --access public
```

Publishing to npm is a separate manual step from the GitHub release workflow.
Use a new package version for each subsequent publication. Do not put registry
tokens in this repository. Third-party license notices are in
THIRD_PARTY_NOTICES.md and the built `dist/licenses` directory.
